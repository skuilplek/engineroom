# Projects

A project is a folder the server has found in your home, usually under `Sites`. Its chats are listed under the folder name in the sidebar.

## Home

When nothing is open, the page asks what you want to work on.

Choose a project and Start chat to open that project's start page. When several projects are available, pick one in the Project menu first. Recent chats lists the latest conversations in projects that are still active. Choose a row to open that chat.

New project, on this page and in the sidebar, adds a folder in your home when your account is allowed to create projects. Enter a folder name. Leave Git URL blank to start an empty repository, or paste a URL to clone one. Create project on the home page, or Create in the sidebar, runs it.

If creating projects is turned off and no repository is available yet, a repository has to be enabled before you can start a chat.

## Sidebar

Search chats filters the project and chat list. Each project row opens that project's start page. The plus beside the name starts a new chat in that project.

A colored dot marks a chat, and a live dot marks one that is still running. The time on the right is when it last changed. Older chats stay collapsed. Show older expands them, and Hide older folds them again. Chats shown per project, in Customize, sets how many stay visible. Use 0 there to show every chat. While a search is active, the list is uncapped.

Archived projects stay in the sidebar under Archived.

## Start page

Open a project to reach its start page. The heading is Let's Start Building! The line under the composer is the folder you are in.

The buttons along the top:

- **Download project** saves the folder as a zip, when project downloads are on. Wait until the zip is ready, then Download. Dismiss closes that prompt.
- **Archive** moves the project under Archived. On an archived project the same button is Unarchive.
- **Delete** asks you to type the folder name. Delete project then removes that folder and its chats.
- **Files** opens the file list when the file manager is on.

## Import CLI sessions

When CLI import is on, Import CLI sessions is in the sidebar. Wait for the list, and pick a Cursor conversation that already exists on this account. It opens as a chat under that project. Close hides the list.
