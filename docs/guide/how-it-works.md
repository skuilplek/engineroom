# How it works

You sign in with your Linux username and password. Chats, project folders, and agent commands run as that account, inside your home directory. The name in the sidebar is the name set for this server.

The administrator decides which agents and tools the server offers, and which of those your account may use. A reply streams into the chat as the agent works. The modes and models in the composer are the ones that agent reports and that this server offers to you.

Cursor and Pi each keep their own sign-in in your home directory. Sign in to each command once from your account. When the terminal is turned on, open Terminal on a chat and use `agent` or `pi` there. After that, new chats can use that agent.

Customize holds your own defaults: theme, the agent and model a new chat starts with, how tool requests are approved, and whether the file viewer is read-only.
