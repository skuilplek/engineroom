# Your account

The account button is at the bottom of the sidebar. It shows your git name when one is saved, and your Linux username under that.

## Git name and email

Open the account menu. If a name and email are missing, the form is already open. Fill both in and choose Save. They are stored as your global git name and email, which commits from this account use. Edit changes them later. This does not rename the Linux account.

## Menu

- **Customize** is your theme, defaults, and packages.
- **Docs** is this guide, plus documents an administrator has added, and notes from packages that are enabled.
- **Errors** appears after a notice has been saved for this account. Open it to read the message again. Clear removes one entry. Clear all removes the list. Dismissing a notice on another page still leaves it here until you clear it.
- **Admin** appears for the administrator. It is covered in the Admin chapter.
- **Sign out** ends this browser session. Chats stay in your home directory.

## Layout

The panel button at the top of the sidebar collapses it. Expand menu opens it again. Full screen, beside that button, fills the browser when the browser allows it. Exit full screen returns to the window.

On a narrow screen the sidebar stays hidden until you choose Open menu. Collapse menu, or the dimmed area beside the sidebar, puts it away. Files, in the top bar, opens the file list when the file manager is on.
