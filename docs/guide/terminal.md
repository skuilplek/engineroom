# Terminal

When the terminal is on for your account, Terminal on a chat replaces the transcript with a shell. The shell runs as your Linux account, in that environment. Chat switches back to the transcript.

Terminal stays disabled while a reply is running. Stop the reply or wait for it to finish, then switch.

Use this shell for the one-time sign-in each agent needs. Cursor is `agent` and Pi is `pi`. Those credentials stay in your home directory.

The terminal is per chat. Switching chats switches shells. Collapse the file list if you want the full width for the session.
