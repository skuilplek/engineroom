| [Git](git.md) | Branches, remotes, pull, push, and commits |
| [Files](files.md) | The file list, editor, search, and changes |
| [Terminal](terminal.md) | The shell on a chat |

What's enabled, in the Docs page, lists the agents and tools on for the account you are signed in as. That list changes with the server, so it is not copied here.
